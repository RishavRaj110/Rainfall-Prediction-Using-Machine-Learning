# Rainfall Prediction Using Machine Learning

## Project Overview
This project uses historical rainfall data to analyze rainfall patterns and predict annual rainfall using Machine Learning algorithms.

## Objectives
- Analyze historical rainfall data.
- Identify rainfall trends and patterns.
- Predict annual rainfall.
- Compare different Machine Learning models.

## Algorithms Used
1. Linear Regression
2. Polynomial Regression
3. Decision Tree Regressor
4. Random Forest Regressor
5. Support Vector Regression (SVR)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Excel

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score
